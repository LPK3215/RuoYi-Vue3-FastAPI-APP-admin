DeskOps Admin

面向业务的软件资源管理平台，包含后台管理、Portal Web、教程博客和移动端

FastAPI · Vue 3 · React · uni-app

项目简介

🎯

核心价值

提供完整的软件资源管理解决方案，包含后台管理（分类/软件/上下架）、Portal Web（浏览/搜索/详情）、教程博客和移动端。

💡

功能模块

  • 后台管理：分类/软件/内容维护
  • Portal Web：软件库浏览/搜索
  • 教程博客：Markdown 渲染 + 关联软件
  • 移动端：uni-app 多端适配
  • 自动化测试：pytest + Playwright

架构全景

技术栈

前端

快速开始

1

启动 Redis 和后端

bash
.\scripts\dev\start-redis.ps1
.\ruoyi-fastapi-backend\run.bat
2

启动管理后台

bash
cd ruoyi-fastapi-frontend
npm install && npm run dev
